MCP Contact Me
Opérationnel

Deux outils privés permettent aux projets IA d’envoyer un message à Tanguy.

Endpoint Streamable HTTP https://mcp-contact-me.tanguym.fr/mcp
Authorization: Bearer <token>
Pile protocolaire
Transport
TCP/IP · TLS
Communication
Streamable HTTP · HTTPS
Appel distant
JSON-RPC 2.0
Intégration
Model Context Protocol

Sorties : SMTP sécurisé · Telegram Bot API via HTTPS

send_email

Envoie un e-mail au nom du projet identifié par son jeton.

Entrée
subject
string requis · 1–160 caractères
message
string requis · 1–3500 caractères
urgency
low | normal | high · défaut normal
Réponse en cas de succès {"status":"sent","channel":"email","project":"<authenticated-project>"}

send_telegram

Envoie un Telegram au nom du projet identifié par son jeton.

Entrée
subject
string requis · 1–160 caractères
message
string requis · 1–3500 caractères
urgency
low | normal | high · défaut normal
Réponse en cas de succès {"status":"sent","channel":"telegram","project":"<authenticated-project>"}

Sécurisé — HTTPS, jetons propres à chaque projet conservés sous forme d’empreinte SHA-256, quotas dédiés et destinataires fixes. Le service reste isolé derrière Caddy et les journaux ne contiennent ni secrets ni messages.

Le projet est déduit du jeton · 5 envois/minute · 50 envois/24 h · Destinataires fixes.
